EdgeMem: LLM-Free Agent Memory Construction and Retrieval via Evidence-Preserving Multi-Anchor Hypergraph

Zeyang Cui、Jiannong Cao 等 · 2026-09-03 · arXiv 预印本

EdgeMem 提出了一种新的代理记忆构建和检索方法，通过保留原始交互回合来避免生成成本和细节丢失。

该方法在LoCoMo和LongMemEval-S数据集上表现出色，且不需要生成式LLM调用，具有高效性。

FlyHash for LLM Agent Memory: An Empirical Validation and a New Application

Mohan Bheemadolu、Chrisogonas O. Odhiambo · 2026-11-04 · arXiv 预印本

FlyHash首次应用于LLM代理记忆检索，通过稀疏随机投影和胜者通吃竞争机制进行哈希计算。

该方法在多个数据集上验证了其质量优势，虽然在实际应用中可能存在延迟和存储开销。

Agent Zero Memory: Provenance-Aware Long-Term Memory for LLM Agents

Ming Wu、Pengyuan Zhu · 2026-08-30 · arXiv 预印本

Agent Zero Memory 提出了一个感知来源的长期记忆系统，包含事件时间线、关联知识图谱和层次文档记忆三种并行记忆系统。

该系统在两个公开基准测试中达到了新的最先进水平，展示了其在准确性和可靠性方面的优势。
